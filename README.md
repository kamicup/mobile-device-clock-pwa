# Mobile Device Clock PWA

GitHub Pages で配信する、iPod touch 6th / iOS 12.5.8 の Safari 向け時計 PWA です。

## 表示内容

- 現在のロケールの年月日と曜日
- 現在のローカル時刻
- 今月のカレンダー
- 現在の GMT 時刻

## デプロイ

`main` ブランチへ push すると、GitHub Actions が GitHub Pages へ静的ファイルをデプロイします。

リポジトリ設定の `Settings > Pages` で Source が `GitHub Actions` になっていることを確認してください。
